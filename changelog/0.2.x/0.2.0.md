# 0.2.0 — 2026-10-28

## Added

- **`uk-legislation-guide` Agent Skill** — served over MCP as `skill://uk-legislation-guide/SKILL.md` (listed in `resources/list`, with the `skill://{+path}` template and the `io.modelcontextprotocol/skills` extension advertised at `initialize`) through `createApp({ skills: 'skills' })`, and shipped under `skills/` in the npm package, Docker image, and `.mcpb`. It covers deciding whether a provision is in force and current, its text on a date, what amended or commenced it, and what changed since a date.
- **Agent Plugins `plugin.json` and `mcp.json`** at the repo root (mcp-ts-core 0.13.18, [cyanheads/mcp-ts-core#426](https://github.com/cyanheads/mcp-ts-core/issues/426)) describe the package and its stdio server as an installable plugin; the `.mcpb` omits both.

## Changed

- **Smaller `.mcpb`** — the bundle now carries only runtime files: the repo's `CLAUDE.md`, `AGENTS.md`, `changelog/`, and plugin manifests, and the framework's build-only files (its `changelog/`, `config/`, `scripts/`, `templates/`, `CLAUDE.md`, `AGENTS.md`, `biome.json`), no longer ship in it (mcp-ts-core 0.13.18 anchored `.mcpbignore` and `clean-mcpb`, [cyanheads/mcp-ts-core#508](https://github.com/cyanheads/mcp-ts-core/issues/508), [#791](https://github.com/cyanheads/mcp-ts-core/issues/791)). The bundle cleaner keeps the MCP SDK's `dist/ext/skills/` runtime, which the published skill needs.
- **`skills/` ships** — listed in `package.json` `files`; the `Dockerfile` creates it in the build stage and copies it into the production image.
- **Tooling and skills resynced** — `scripts/` (`check-skills-sync`, `clean-mcpb`, `devcheck`, `lint-packaging`), the framework skills under `framework-skills/` (new `add-skill`), and the bug report form, which now takes one Environment table.
- **`bunfig.toml` `minimumReleaseAge`** is 1 day (was 3).
- **README Getting started** leads with the hosted instance and `npx`; Docker and clone-and-install moved under Running the server, and a Resources table lists the skill.
- **Docs** — `docs/design.md`, `CLAUDE.md`, and `AGENTS.md` describe the skills wiring.
- **Tests** — an ATX-heading round trip for `inline`, and `tests/scripts/agent-doc-entry.test.ts` for the bundle agent-doc selector.

## Fixed

- **HTTP memory** — mcp-ts-core 0.13.17 stops retaining each HTTP request's signal ([cyanheads/mcp-ts-core#786](https://github.com/cyanheads/mcp-ts-core/issues/786)). On 0.1.3 (mcp-ts-core 0.13.16) memory grew with every HTTP request under Bun, the runtime the Docker image runs; stdio is unaffected.
- **Headings keep a trailing `#`** — mcp-ts-core 0.13.18's `escapeMarkdownInline` escapes the last `#` of a trailing ` #` run ([cyanheads/mcp-ts-core#781](https://github.com/cyanheads/mcp-ts-core/issues/781)), so a legislation or provision title ending in ` #` keeps that `#` in `content[]` headings instead of losing it as a closing sequence.
