# 0.1.3 — 2026-10-25

## Changed

- **Framework runtime** adopts bounded Zod error details from `mcp-ts-core` 0.13.15; 0.13.16 supplies Markdown-safe error and enrichment text, startup configuration diagnostics and validation, and cancellation handling.
- **Development tooling and docs** sync framework checks and skills, exclude source and development directories from MCPB bundles, document hosted client configuration, and measure parser performance tests with CPU time.

## Fixed

- **Inline Markdown output** uses `escapeMarkdownInline` for inline values and table cells so entity-shaped text, heading markers, links, HTML, and pipes render literally; authored CLML Markdown remains formatted.
